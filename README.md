# hexa-studio-prototypes (retired)

This repo used to host web exports of Hexa prototypes for usability testing: a static Log In → Dashboard page and a
password-protected Log In → OTP → Dashboard pilot. Both were removed on 2026-11-25.

Coded prototypes now live in [`Hexa-Design-System/code/`](https://github.com/CheyMae/Hexa-Design-System/tree/main/code)
and run as Figma code layers. The old pages are still in this repo's Git history.
